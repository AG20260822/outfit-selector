This is a generic image-classification model. It is NOT expected to identify clothing perfectly. The purpose of this test is to prove that your phone can run the AI and return usable predictions.
WHY ARE WE TESTING THIS?
First we need to establish that Chrome on your phone can reliably run a small computer-vision model locally. Once that works, we can move on to a clothing-specific model.
