WHY ARE WE TESTING THIS?
This is intentionally NOT the final wardrobe AI. First we want to establish that your phone's Chrome browser can reliably run a very small computer-vision model locally. If this works, we can then move to a clothing-specific model or build a lightweight clothing-recognition layer on top of this foundation.
